# 本地演示指南

## 前置要求

- 电脑已安装 [Node.js](https://nodejs.org/)（推荐 v18.0.0 或更高版本）
- npm 包管理器（Node.js 自带）
- 网络连接（需要加载高德地图 API）

## 启动步骤

### 1. 进入项目目录

```bash
cd my-travel
```

### 2. 安装依赖（首次运行）

```bash
npm install
```

如果遇到安装速度慢，可以使用国内镜像：

```bash
npm install --registry=https://registry.npmmirror.com
```

### 3. 启动开发服务器

```bash
npm run dev
```

### 4. 访问页面

启动后终端会显示访问地址，默认打开 `http://localhost:5173`。

## 手机访问（同Wi-Fi演示）

1. 电脑和手机连接到**同一个 Wi-Fi 网络**
2. 在电脑终端查看本机 IP 地址：
   - Windows: 在命令提示符中输入 `ipconfig`，查看"IPv4 地址"
   - Mac: 系统偏好设置 → 网络 → 查看 IP
3. 手机浏览器访问 `http://电脑IP:5173`（例如 `http://192.168.1.100:5173`）

### 电脑防火墙开放 5173 端口

**Windows 用户**：如果手机无法访问，请按以下步骤操作：

1. 打开「控制面板」→「Windows Defender 防火墙」→「高级设置」
2. 选择「入站规则」→「新建规则」
3. 规则类型选「端口」→ 下一步
4. 填写 `5173` → 下一步
5. 选择「允许连接」→ 下一步
6. 勾选所有配置文件 → 下一步
7. 输入名称 `Vite Dev Server` → 完成

## 常见问题

### 页面打不开
- 检查终端是否显示服务已启动
- 确认访问地址是否为 `http://localhost:5173`
- 检查是否有其他程序占用了 5173 端口

### 依赖安装失败
- 使用 `npm install --registry=https://registry.npmmirror.com` 重试
- 删除 `node_modules` 目录和 `package-lock.json`，重新安装
- 更新 Node.js 到最新 LTS 版本

### 端口占用
如果 5173 端口被占用，Vite 会自动尝试下一个可用端口（如 5174），请以终端显示的地址为准。

```bash
# 手动指定端口启动
npx vite --port 5173
```

### 手机无法访问
- 确认手机和电脑在同一 Wi-Fi 网络
- 确认防火墙已放行 5173 端口
- 尝试用电脑 IP 地址而非 localhost 访问
- 部分手机浏览器可能需要开启"允许访问本地网络"设置
